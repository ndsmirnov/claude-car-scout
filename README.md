# Подбор машины с Авито через нейросеть

![Подбор машины](assets/cover.jpg)

Claude Code просматривает живые объявления Авито вместо тебя и сводит их в одну таблицу:

- **безопасность**: подушки, системы стабилизации, краш-тесты поколения;
- **стоимость владения за год**: налог, ОСАГО, ТО, топливо (по блоку «Стоимость владения» с самого Авито);
- **ликвидность**: легко ли потом продать;
- **надёжность**: известные болячки мотора и коробки.

Главное, что он умеет: читать **полное описание продавца** и находить то, что прячут в тексте. «Требуется ремонт турбины», «после ДТП», «дубликат ПТС», «срочно, торг у капота». По каждой машине он ставит вердикт «кандидат», «осторожно» или «отказ» и объясняет почему.

На выходе ты получаешь таблицу у себя на компьютере (открывается в браузере, удобно и с телефона), список вопросов продавцу и чеклист осмотра.

**Бесплатно.** Я сам собирал подбор так: объявления выгружал через сайт Apify на бесплатном тарифе ($5 кредитов в месяц, этого хватает примерно на тысячу объявлений), разбирал их в Claude Code. Отдельно платить не пришлось.

## Что понадобится

- Подписка Claude Pro ($20 в месяц) или выше: Claude Code входит во все платные планы, на бесплатном его нет.
- Mac или Windows.
- Бесплатный аккаунт на [apify.com](https://apify.com) — по желанию. Без него тоже работает: копируешь текст объявления со страницы Авито и вставляешь в чат.

## Как поставить

1. Поставь Claude Code. На Mac: открой Терминал (Cmd+Пробел → «Терминал»), вставь команду и нажми Enter:

   `curl -fsSL https://claude.ai/install.sh | bash`

   Затем открой новое окно Терминала, напиши `claude` и войди в свой аккаунт Claude.
2. В Claude Code напиши:

   `Установи скилл подбора машины из https://github.com/ndsmirnov/claude-car-scout`

3. Он спросит: бюджет, город, для чего машина, что точно не подходит. Отвечай как есть, можно голосом (диктовка Mac: дважды Fn).
4. Дальше он покажет, как выгрузить объявления (через сайт Apify или вручную), и соберёт таблицу.

## Как пользоваться

- **Новый поиск:** «подбери машину» — он возьмёт твои ответы из прошлого раза и спросит только, что изменилось.
- **Одно объявление:** открой его на Авито, выдели всё на странице (Cmd+A), скопируй и вставь в чат с фразой «разбери объявление». Особенно блок «Стоимость владения» и описание продавца.
- **Таблица** лежит в `~/car-scout/таблица.html`. Её можно открыть двойным кликом и отправить себе на телефон.

## Что внутри

# Инструкция для Claude (выполни по порядку)

Ты ставишь пользователю скилл подбора машины. Он может быть не разработчиком: объясняй коротко и по-русски, после каждого шага одной строкой пиши, что сделано.

1. `PKG` = папка, где лежит этот README. Если пользователь дал ссылку на GitHub — скачай архив: `curl -sL https://github.com/ndsmirnov/claude-car-scout/archive/refs/heads/main.tar.gz | tar -xz -C /tmp`, тогда `PKG` = `/tmp/claude-car-scout-main` (git не нужен; именно tar.gz — `unzip` на Mac ломает русские имена файлов).
2. Скопируй скилл: `mkdir -p ~/.claude/skills && cp -R "$PKG/skills/car-scout" ~/.claude/skills/`.
3. Прочитай `~/.claude/skills/car-scout/SKILL.md` и выполни его с шага 0.
